🧠 Memory Card Game (ReactJS)

A dynamic and interactive Memory Card Game built with React.js, focused on clean component architecture, efficient state management, and scalable UI logic.

The objective is simple: click each card only once. After every selection, the cards reshuffle. Selecting a previously clicked card resets the game.

⸻

🚀 Tech Stack
	•	React.js
	•	JavaScript (ES6+)
	•	CSS3
	•	React Hooks (useState)

⸻

🎯 Key Features
	•	Score and best score tracking
	•	Game reset on duplicate selection
	•	Reusable component-based architecture
	•	Responsive layout

⸻

🧠 Concepts Demonstrated
	•	State management with React Hooks
	•	Event handling and conditional logic
	•	Component reusability
	•	Clean and maintainable frontend structure
